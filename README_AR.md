# KashKool v70 — نسخة Windows النهائية

هذه الحزمة تجمع واجهة KashKool v70 وملفاتها المقسّمة مع مشغّل Electron الخاص بالكمبيوتر. تم الحفاظ على ترتيب ملفات JavaScript لأن بعض أجزاء التطبيق تعتمد على الأجزاء التي تسبقها.

## بناء البرنامج على Windows

1. فك ضغط `KashKool_v70_Ready.zip` كاملًا داخل مجلد عادي، ولا تشغّل ملفات البناء من داخل نافذة ZIP.
2. ثبّت Node.js 24 على Windows، ثم أغلق نافذة الأوامر وافتحها من جديد.
3. افتح مجلد `KashKool_v70_Ready`.
4. شغّل `BUILD_WINDOWS.bat`. سيفتح سطر أوامر منفصلًا وسيظل مفتوحًا حتى بعد انتهاء العملية أو حدوث خطأ.
5. عند اكتمال البناء افتح مجلد `dist`.

ستجد ملف تثبيت KashKool ونسخة Portable. ملف التثبيت ينشئ اختصار سطح المكتب وقائمة Start. البناء يستخدم نسخًا محددة من Electron وelectron-builder بدل الاعتماد على `latest` المتغير.

## التشغيل في الخلفية والإشعارات

- زر X أو تصغير النافذة يخفي KashKool إلى أيقونته بجوار ساعة Windows؛ لا ينهي العملية.
- اضغط أيقونة KashKool في شريط النظام لفتح النافذة، أو اضغط بزر الفأرة الأيمن لعرض القائمة.
- من القائمة يمكنك اختيار `Run when Windows starts` لتشغيل البرنامج مع Windows بعد تثبيت النسخة.
- لإنهاء البرنامج تمامًا اختر `Quit KashKool` من قائمة الأيقونة.
- فعّل الإشعارات من إعدادات KashKool، ثم اضغط زر الإشعار التجريبي.
- يجب أن يكون Windows مسموحًا له بإظهار إشعارات KashKool. لا يمكن إرسال تذكير عندما يكون الجهاز مطفأ أو في وضع Sleep.

يظل المؤقت وفحص المواعيد يعملان ما دام البرنامج موجودًا في شريط النظام. لا تعتمد نسخة Windows على بقاء نافذة البرنامج ظاهرة.

## Firebase والحسابات

إعداد Web الخاص بمشروع `kashkool-cloud` مضمّن داخل التطبيق ويُستخدم افتراضيًا لكل التثبيتات، لذلك لا يحتاج المستخدم إلى نسخ JSON يدويًا.

الإعدادات المضمّنة ليست كلمة مرور أو مفتاحًا خاصًا. يجب على مالك Firebase التأكد من تشغيل Email/Password Authentication وCloud Firestore، وضبط قواعد Firestore بحيث لا يستطيع المستخدم قراءة أو تعديل إلا بيانات حسابه. أضف `localhost` إلى Authorized domains عند الحاجة. تضمين الإعدادات وحده لا ينشئ قواعد قاعدة البيانات ولا يفعّل الخدمات نيابةً عن مالك المشروع.

## فحص سلامة الملفات

من داخل مجلد المشروع شغّل:

```bat
npm install
npm run check
```

يفحص الأمر ملفات JavaScript، وترابط ملفات HTML، ووجود إعداد Firebase، والجسر بين الإشعارات وتطبيق Windows. يقوم `BUILD_WINDOWS.bat` بهذا الفحص تلقائيًا قبل إنشاء ملفات EXE. تُحفظ تفاصيل التنزيل والبناء في `BUILD_LAST_LOG.txt` داخل مجلد المشروع؛ أرسل هذا الملف عند ظهور خطأ بدل إغلاق النافذة.

## ملاحظة عن البيانات

يستخدم تطبيق Windows أصلًا محليًا ثابتًا `http://localhost:48762` حتى يظل تخزين المتصفح المحلي وتسجيل دخول Firebase وخدمة العمل دون اتصال محفوظة بين مرات التشغيل. لا تغيّر المنفذ في `desktop/main.cjs` بعد بدء استخدام التطبيق، لأن تغيير المنفذ يغيّر أصل التخزين المحلي وقد يجعل البيانات القديمة غير ظاهرة.
