KashKool Mobile v40 — Username / Password + Cloud Sync setup

محتويات الحزمة:
- index.html: التطبيق الرئيسي.
- kashkool.webmanifest: إعدادات تثبيت التطبيق على الشاشة الرئيسية.
- kashkool-sw.js: Service Worker لتخزين غلاف الموقع مؤقتًا.

النشر على GitHub Pages:
1) ارفع الملفات الثلاثة إلى جذر مستودع KashKool-Mobile.
2) تأكد أن الصفحة الرئيسية اسمها index.html.
3) من Settings > Pages تأكد أن GitHub Pages منشور من الفرع والمجلد الصحيحين.
4) افتح الموقع عبر HTTPS ثم حدّثه تحديثًا قويًا أو امسح كاش الموقع إذا بقيت النسخة القديمة.

تنبيه مهم:
- الحزمة مجهزة للاتصال بـ Firebase، لكنها لا تتضمن مشروع Firebase خاصًا بك ولا إعداداته.
- لتفعيل الحسابات فعليًا: أنشئ Firebase project، أضف Web App، فعّل Authentication > Email/Password، أنشئ Cloud Firestore، وانشر قواعد الأمان الموجودة داخل واجهة التطبيق.
- ضع إعدادات Firebase Web App بصيغة JSON داخل إعدادات الحساب والمزامنة في التطبيق على كل جهاز إذا لم تكن مضمّنة في النسخة المنشورة.
- اختبر الحساب والمزامنة قبل الاعتماد عليها، واحتفظ بنسخة احتياطية من بياناتك.
- لا ترفع كلمات مرور أو مفاتيح سرية خاصة بالخادم إلى المستودع. إعدادات Firebase Web App العادية ليست بديلًا عن قواعد أمان Firestore.
